# Security policy

Do not open public issues for suspected vulnerabilities, exposed credentials, or
content/privacy concerns. Use GitHub's **Report a vulnerability** flow to open a private
security advisory with the maintainers, including a clear reproduction and impact
assessment. Do not include secrets, user data, or private corpus content in public channels.

The public demo is not a production service. Deployers must provision their own
Cloudflare resources, secrets, rate limits, and monitoring before serving users.
